# Видео LTX-2.5

Инструмент: `python -m designer video`. Два бэкенда, флаг `--via`:

- **`space` — бесплатно.** Официальное демо `Lightricks/LTX-2.5` на Hugging Face, модуль
  `designer/ltx_space.py`, нужен пакет `gradio_client`.
  - Ограничения: 1–5 с (или `--duration auto` до 15 с), кадр не больше 832x1472, звук всегда.
  - Камера описывается словами: `--camera` дописывает фразу в промпт.
  - Последнего кадра и аудио на входе нет.
  - Квота дневная. Нужен токен Hugging Face: секрет окружения для хоста
    `lightricks-ltx-2-5.hf.space` (заголовок `x-hf-authorization`, Bearer) или переменная `HF_TOKEN`.
  - С бесплатным аккаунтом выходит несколько коротких роликов в день, с HF PRO — в 8 раз больше.
- **`api` — платно, без этих ограничений.** Официальный LTX API v2, модуль `designer/ltx.py`.
  - Нужен `LTXV_API_KEY` (console.ltx.io → API Keys).
  - В облачной сессии ключ может стоять секретом окружения для `api.ltx.io`: тогда передай
    любой `LTXV_API_KEY=dummy`, прокси подставит настоящий.
- По умолчанию `auto`: `api`, если есть `LTXV_API_KEY`, иначе `space`.

**Кадры в `space` уходят в публичный сервис третьей стороны (Hugging Face).** Материалы
клиента туда — только с явного согласия человека. Без согласия — текст → видео или платный
API.

Лицензия открытых весов LTX-2.x бесплатна для компаний с выручкой до $10 млн в год. Более
крупным компаниям для коммерческой работы нужна платная лицензия Lightricks. Если ролик
делается для такого клиента, напомни об этом. Вопросы по API: инструмент `mcp__ltx-docs__searchDocs`, если подключён
MCP документации (`claude mcp add --transport http ltx-docs https://docs.ltx.io/_mcp/server`),
иначе https://docs.ltx.io/llms.txt (к адресу любой страницы можно дописать `.md`).

## Что выбрать

| Задача | Режим |
|---|---|
| Идея, мудборд, сцена с нуля | текст → видео: только промпт |
| Оживить кадр раскадровки, рендер, макет | `--image кадр.png` (кадр остаётся первым кадром ролика) |
| Переход A → B, морфинг, пролёт между ракурсами | `--image A.png --last-frame B.png` |
| Клип под музыку или голос | `--audio трек.mp3` (+ `--image`), длина = длина аудио: 2–20 с у fast на 720p/1080p, иначе 2–10 с |

Модели платного API: `fast` — дешевле, длинные планы (на 720p/1080p при 24/25 fps до 20 с);
`pro` — качественнее (6/8/10 с). Сида в API нет: каждый запуск — новый дубль. Черновик на
`fast 720p` проверяет промпт и движение, но не повторится один в один. Если важен сам дубль,
сразу генерируй с финальной моделью и разрешением.
Первый кадр, переход A → B и клип под трек из таблицы работают в платном API. Бесплатное
демо умеет только текст → видео и оживление одного кадра.

## Цены платного API (за секунду, звук включён)

fast: 720p $0.09 · 1080p $0.13 · 1440p $0.19 · 4K $0.30.
pro: 720p $0.12 · 1080p $0.17 · 1440p $0.25 · 4K $0.39.
`--estimate` считает цену без запроса. Лимит на ролик — `LTX_MAX_USD` (по умолчанию $5).
Перед запуском называй человеку цену одной строкой. Если серия роликов дороже $10,
сначала спроси.

## Промпт (по гайду LTX)

- Пиши по-английски: гайд LTX и все его примеры на английском. Реплики пиши в кавычках
  на нужном языке.
- Одиночный план: один абзац в настоящем времени, обычно 4–8 предложений. Порядок такой:
  план и оптика → свет, палитра, фактуры → действие по шагам (глаголы: *glides, turns,
  flickers*) → движение камеры и что видно после него → звук (эмбиент, музыка, речь).
- Сцена с репликами и несколькими битами пишется в сценарном виде: заголовок сцены,
  имена, реплики в кавычках. Длина по сложности, но каждое предложение должно добавлять
  конкретику. Промпт от другой модели (Kling, Seedance) перепиши в этот формат.
- Эмоции через физику («сжимает руль»), а не ярлыки («нервничает»).
- Одна логика света на план. Сцена сфокусирована: мало героев, ясное действие.
- Для `--image`: описывай движение и то, что меняется. Не пересказывай картинку и не
  ставь склейки: кадр должен остаться одним дублем.
- Мульти-шот (только текст → видео): один абзац по хронологии, на каждой склейке
  назови переход («A hard cut to…»), заново опиши план и скажи, что со звуком.
  Лучше 2–4 плана.
- Тайминг задаётся текстом («a beat of silence»), иначе модель его не добавит.
  С `--duration auto` длину выбирает модель.
- Надписи и логотипы LTX может исказить. Бренд-текст (TEZKOR, Uzum) не проси
  нарисовать. Бери кадр, где надпись уже есть, через `--image`, держи камеру
  спокойной (`dolly_in`, `static`) или добавляй надпись на монтаже.

## Примеры

```bash
python -m designer video "Slow push-in through a glowing purple tunnel, cyan light strips streak past, the end portal grows brighter; deep electronic hum rising." --image frame.png --camera dolly_in --res 720p
```

```bash
python -m designer video "..." --image A.png --last-frame B.png --duration 8 --model pro
```

```bash
python -m designer video "..." --res 1080p --aspect 9:16 --duration auto --estimate
```

```bash
python -m designer video "A paper boat drifts across a calm pond at sunrise; soft birdsong." --via space --duration 3 --seed 7
```

Готовый mp4 появляется в `dist/` (папка не коммитится).

## Сдача

- Человеку отдай mp4 через SendUserFile.
- В Figma mp4 через MCP не загрузить. Положи рядом с кадром превью-GIF:
  `ffmpeg -i clip.mp4 -vf "fps=12,scale=640:-1:flags=lanczos" -loop 0 clip.gif`, затем
  `upload_assets`. Сам mp4 отдай отдельно.
- Ключ проверяется бесплатно: `python -m designer video --check`.
- Другие входы: Telegram — `/video …` текстом или подписью к фото; GitHub — Actions → Video (LTX-2.5).

## Ошибки

- Бесплатное демо: «квота кончилась». Без токена Hugging Face квоты почти нет. С токеном
  жди следующих суток или возьми HF PRO. Без ограничений работает платный API.

- 401 — неверный ключ.
- 402 — закончились кредиты (console.ltx.io → Billing).
- 422 — сработал фильтр безопасности: переформулируй.
- 429 — очередь полна: клиент сам повторит. Одновременно идут 2 задачи, ещё до 100 ждут.
- Ссылка на результат живёт недолго, клиент скачивает файл сразу. Если скачивание
  сорвалось, видео уже оплачено. Не генерируй заново, а забери его:
  `python -m designer video --job <endpoint>/<id>`. id печатается при постановке задачи
  и есть в тексте ошибки; статус хранится до 24 ч, ссылку клиент обновит сам.
