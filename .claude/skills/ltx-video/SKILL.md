# Видео LTX-2.5

Инструмент: `python -m designer video` (модуль `designer/ltx.py`, официальный LTX API v2).
Нужен `LTXV_API_KEY` (console.ltx.io → API Keys). В облачной сессии ключ может стоять
секретом окружения для `api.ltx.io`: тогда передай любой `LTXV_API_KEY=dummy`, прокси
подставит настоящий. Вопросы по API: инструмент `mcp__ltx-docs__searchDocs`, если подключён
MCP документации (`claude mcp add --transport http ltx-docs https://docs.ltx.io/_mcp/server`),
иначе https://docs.ltx.io/llms.txt (к адресу любой страницы можно дописать `.md`).

## Что выбрать

| Задача | Режим |
|---|---|
| Идея, мудборд, сцена с нуля | текст → видео: только промпт |
| Оживить кадр раскадровки, рендер, макет | `--image кадр.png` (кадр остаётся первым кадром ролика) |
| Переход A → B, морфинг, пролёт между ракурсами | `--image A.png --last-frame B.png` |
| Клип под музыку или голос | `--audio трек.mp3` (+ `--image`), длина = длина аудио, 2–20 с |

Модели: `fast` — черновики и длинные планы (на 720p/1080p при 24/25 fps до 20 с);
`pro` — чистовик (6/8/10 с). Сначала черновик на `fast 720p`, потом чистовик.

## Цены (за секунду, звук включён)

fast: 720p $0.09 · 1080p $0.13 · 1440p $0.19 · 4K $0.30.
pro: 720p $0.12 · 1080p $0.17 · 1440p $0.25 · 4K $0.39.
`--estimate` считает цену без запроса. Лимит на ролик — `LTX_MAX_USD` (по умолчанию $5).
Перед запуском называй человеку цену одной строкой. Если серия роликов дороже $10,
сначала спроси.

## Промпт (по гайду LTX)

- Пиши по-английски: гайд LTX и все его примеры на английском. Реплики пиши в кавычках
  на нужном языке.
- Один абзац, настоящее время, 4–8 предложений: план и оптика → свет, палитра,
  фактуры → действие по шагам (глаголы: *glides, turns, flickers*) → движение камеры
  и что видно после него → звук (эмбиент, музыка, речь).
- Эмоции через физику («сжимает руль»), а не ярлыки («нервничает»).
- Одна логика света на план. Сцена сфокусирована: мало героев, ясное действие.
- Для `--image`: описывай движение и то, что меняется. Не пересказывай картинку и не
  ставь склейки: кадр должен остаться одним дублем.
- Мульти-шот (только текст → видео): один абзац по хронологии, на каждой склейке
  назови переход («A hard cut to…»), заново опиши план и скажи, что со звуком.
  Лучше 2–4 плана.
- Тайминг задаётся текстом («a beat of silence»), иначе модель его не добавит.
  С `--duration auto` длину выбирает модель.
- Надписи и логотипы LTX может исказить. Бренд-текст (TEZKOR, Uzum) не проси
  нарисовать. Бери кадр, где надпись уже есть, через `--image`, держи камеру
  спокойной (`dolly_in`, `static`) или добавляй надпись на монтаже.

## Примеры

```bash
python -m designer video "Slow push-in through a glowing purple tunnel, cyan light strips streak past, the end portal grows brighter; deep electronic hum rising." --image designer/tunnel3d/fin_294_B.png --camera dolly_in --res 720p
```

```bash
python -m designer video "..." --image A.png --last-frame B.png --duration 8 --model pro
```

```bash
python -m designer video "..." --res 1080p --aspect 9:16 --duration auto --estimate
```

Готовый mp4 появляется в `dist/` (папка не коммитится). Отдай его человеку: SendUserFile
или Figma. Telegram: `/video …` текстом или подписью к фото. GitHub: Actions → Video (LTX-2.5).

## Ошибки

- 401 — неверный ключ.
- 402 — закончились кредиты (console.ltx.io → Billing).
- 422 — сработал фильтр безопасности: переформулируй.
- 429 — очередь полна: клиент сам повторит. Одновременно идут 2 задачи, ещё до 100 ждут.
- Ссылка на результат живёт недолго. Клиент скачивает файл сразу; статус задачи
  хранится 24 ч.
