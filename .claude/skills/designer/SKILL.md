# Дизайнер

Библиотека: `designer/library/<slug>/DESIGN.md` (84 стиля, MIT, VoltAgent/awesome-design-md).
Индекс со slug, темой, палитрой и шрифтами: `designer/library/catalog.json`.
Галерея для человека: `python -m designer gallery` → `dist/gallery.html`.

## Порядок работы

1. **Бриф.** Нужно понять: что делаем (формат), для кого, одна главная задача страницы,
   реальный контент. Если чего-то критичного нет, задай один короткий вопрос; остальное
   додумай правдоподобно и отметь это в ответе. Факты о человеке (резюме) не выдумывай:
   бери из `resume/resume.md` или из брифа.
2. **Стиль.** Если человек назвал стиль, найди его: `python -m designer show <имя>`.
   Если нет — предложи три разных направления (одно тёмное, одно светлое, одно смелое)
   из `catalog.json` с объяснением в одну строку и дай выбрать. Есть ключ Claude API —
   можно `python -m designer suggest "<бриф>"`.
3. **Прочитай DESIGN.md целиком.** Это закон: токены цветов и их роли, типографическая
   шкала, отступы, радиусы, тени, рецепты компонентов, Do's and Don'ts.
4. **21st.dev (если доступны инструменты `mcp__21st__*`).**
   - `search` / `get_inspiration` — бесплатно: найди 2–4 компонента под самую сложную
     секцию (прайсинг, отзывы, дашборд…).
   - `get_component` — тратит квоту (на free-тарифе 2 в день): сначала `get_usage`,
     бери не больше одного компонента на дизайн.
   - Код компонента — референс структуры и интерактива. Переноси в ванильный
     HTML/CSS/JS и перекрашивай токенами DESIGN.md; не копируй их цвета, шрифты,
     тексты и Tailwind-классы.
   - `search_logo` — только для логотипов, которые человек явно попросил (свой бренд,
     перечисленный стек).
   - Инструменты правки и удаления аккаунта 21st запрещены в `.claude/settings.json`.
5. **Сборка.** Один самодостаточный HTML в `dist/`:
   - токены DESIGN.md как CSS-переменные на `:root`, весь CSS и JS внутри файла;
   - фирменные шрифты недоступны — ближайший аналог с Google Fonts + fallback-стек;
   - никаких внешних картинок: CSS, инлайновый SVG (иконки, иллюстрации, графики, мокапы UI);
   - это бренд клиента: не используй имя, логотип и слоганы компании-референса;
   - семантичная разметка, контраст WCAG AA, видимый фокус, `prefers-reduced-motion`;
   - без горизонтального скролла на 360px (кроме форматов фиксированного размера);
   - не тащи «дефолтный AI-стиль», если DESIGN.md его не требует: кремовый фон,
     курсивные акценты в заголовках, нумерация 01/02/03, моно-лейблы, кнопки-таблетки.
   Спецификации форматов (дек 16:9 с навигацией и печатью в PDF, письмо на таблицах
   600px, артборды 1080×1080/1350/1920 и т.д.) — в `designer/studio.py`, словарь `KINDS`.
6. **Проверка.** Один раз сними скриншоты Playwright (Chromium предустановлен)
   на 1440px и 390px, поправь то, что видно, и отдавай.
7. **Сдача.** Путь к файлу, выбранный стиль и почему, что додумано, какой референс
   21st взят.

## Без Claude Code

Тот же пайплайн из терминала, Telegram-бота (`/design`) и GitHub Actions (workflow
«Designer»): `python -m designer make "<бриф>" [--kind deck] [--style linear] [--polish]`.
