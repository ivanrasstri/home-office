# Окопная хроника — бодикам-шутер в окопах

Браузерный шутер от первого лица в стиле нагрудной камеры по мотивам вселенной Trench Crusade. Фанатский прототип только для личного использования.

## Как запустить

**Проще всего — по ссылке на артефакт** (её даёт Claude). Ничего ставить не нужно.

**Локально:** нужен Node.js или Python 3, потому что браузер не даёт загружать текстуры с `file://`.
- Windows: дважды кликнуть `play.bat`
- macOS / Linux: `./play.sh`
- или вручную: `node tools/serve.mjs` и открыть http://localhost:8080/

Нужен компьютер с мышью и клавиатурой и нормальной видеокартой. Качество графики выбирается в меню. Если кадров мало, игра сама снижает разрешение.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | осмотр / выстрел |
| ПКМ | вскинуть винтовку к плечу (прицел по мушке и целику) |
| R | перезарядка по одному патрону; выстрел прерывает её |
| V | удар штыком |
| G | граната |
| Q | перевязка: снимает маркер крови (58 % успеха, как в книге) |
| X | противогаз |
| Shift / C | бег / присесть |
| F | фонарь |
| Esc | пауза |

## Задания

- **Удержать до рассвета.** Шесть атак. Враги приходят с Ничьей земли, часть спрыгивает в окоп с бруствера. На третьей и пятой атаке газ, на чётных — артобстрел.
- **Ночной рейд.** Вы спрыгиваете во вражескую сапу. Нужно найти реликвию в дальнем блиндаже и вернуться. Гарнизон стоит часовыми и видит вас по фонарю, бегу и вспышкам выстрелов. Если поднимется тревога, подойдут подкрепления.
- **Бесконечная ночь.** Волны без конца, газ и обстрел выпадают случайно.

## Правила из книги

Механики перенесены из официальной книги правил Trench Crusade (подробности в `docs/GAME_MAPPING.md`):

- **Маркеры крови.** Каждое попадание кладёт маркер, осколки и газ кладут лишний. Маркеры раскачивают прицел, пачкают объектив и снижают предел здоровья. Шесть маркеров дают врагу кровавую баню.
- **Сбит с ног.** Тяжёлый удар роняет камеру в грязь, встаёте вы с половинной скоростью. То же работает для врагов.
- **Шанс попадания врагов** считается по ступеням кубиков книги: −2 = 17 %, 0 = 58 %, +2 = 91 %. Укрытие (присесть), дальняя дистанция и бег снижают шанс.
- **Броня** гасит урон в корпус (−1, −2, −3), выстрел в голову — крит, он броню игнорирует. Элита переживает первую смертельную рану (TOUGH).
- **Мораль отрядов.** Когда половина отряда лежит, он проверяет боевой дух. Живой командир помогает. Первый провал — «дрогнули», второй — отряд бежит.
- **Взрывы** задевают только тех, кто видит точку взрыва: стенка окопа спасает. Демоническая граната бьёт сквозь стены.
- **СТРАХ.** По демонам штык бьёт хуже.

## Что внутри

### Графика

**Фотосканы Poly Haven (CC0):**
- поверхности: мокрая грязь, земляные стенки, выжженная ничейная земля, обшивка из досок, ржавое рифлёное железо, мешковина;
- модели: винтовка Мосина, противогаз, фонари «летучая мышь», армейские ящики, лопата, бочки, печка, мёртвые деревья, пни, корни, крысы.

**Окопы:**
- карта высот с земляными стенками, бруствером и воронками, часть воронок залита водой;
- реалистичная схема траншей: передняя линия с траверсами, линия поддержки, резервная линия, ходы сообщения зигзагом, сапы к постам подслушивания, блиндажи с крышами.

**Свет:**
- луна с тенями;
- нагрудный фонарь с рисунком отражателя и тенями;
- осветительные ракеты на парашюте, тени от них качаются;
- фонари и печки в окопе;
- вспышки выстрелов и далёкой артиллерии;
- ночной HDRI для отражений.

**Конвейер нагрудной камеры:**
- SSAO;
- объёмный туман: в нём видны луч фонаря с тенями и ореолы ламп;
- экранные отражения в лужах;
- bloom;
- автоэкспозиция с «дыханием», как у настоящей камеры;
- фишай, хроматическая аберрация, смаз при повороте, rolling shutter;
- шум сенсора (сильнее в темноте), перешарп, макроблоки компрессии, капли дождя на объективе.

**Дождь:** считается на GPU и виден в луче фонаря, по лужам расходятся круги.

### Враги

Отряды взяты из книги правил:

- **Против Верных** (Легионы Еретиков и Двор Семиглавого Змея): еретик-пехотинец, Отверженный в железной маске, ярмовой бес в шипастом наморднике, пулемётчик (стреляет только с места, потом долго перезаряжается), ветеран в броне Кобара с топором палача.
- **Против Еретиков** (Новый Антиох и окопные пилигримы): йомен, бичеватель в железном шлеме, церковный узник со смертным зарядом, штурмовик с пистолетом-пулемётом, снайпер-священник с бликом оптики, Коммуникант с противоматериальным ружьём.

Как это устроено:
- скелетные модели с mocap-анимацией, руки держат оружие через IK;
- роли ИИ: стрелок, рукопашник, тяжёлое оружие, снайпер, смертник;
- часовые и патрули для рейда;
- хитбоксы по костям, попадание в голову ×2,6.

В меню есть **архив**: статьи о мире, фракциях и арсенале по книге и карточки всех врагов игры.

### Звук

Весь синтезирован в WebAudio и пропущен через «микрофон камеры»: компрессия и перегруз. Есть эхо узкой траншеи, щелчки пролетающих пуль, свои звуки попаданий в землю, доски и железо, дождь, ветер.

## Файлы

- `index.html` — страница, меню, интерфейс камеры
- `src/` — исходники (ES-модули):
  - `main.js` — игрок и волны
  - `trenchmap.js` — схема окопов и рельеф
  - `terrain.js` — шейдер грязи
  - `dressing.js` — оснащение окопа
  - `post.js` — конвейер камеры
  - `enemies.js` — враги
  - `weapon.js` — оружие
  - `fx.js` — частицы и дождь
  - `audio.js` — звук
  - `lights.js` — свет
  - `sky.js` — небо
  - `hazards.js` — взрывы, гранаты, газ, артобстрел
  - `content.js`, `lore-data.js` — архив, подсказки, арты
  - `music.js` — музыка
- `dist/game.js` — собранная игра (`npm run build`)
- `assets/` — текстуры, модели, HDRI (около 35 МБ), список источников в `assets/CREDITS.txt`
- `tools/fetch-assets.mjs` — заново скачать и обработать ассеты с Poly Haven (`npm run assets`)
- `legacy/game-v1.js` — первая версия на примитивах
- `docs/LORE.md`, `docs/GAME_MAPPING.md`, `docs/ART.md` — исследование книги правил: лор, перенос правил в шутер, разбор артов (пересказ, без текста и иллюстраций книги)
- `assets-private/` — приватная папка, её нет в репозитории: арты из книги и музыка. Без неё игра работает, просто без иллюстраций и с генеративной музыкой.

Для разработки: `npm install`, затем `npm run dev` (пересборка на лету) и `npm run serve`.

## Ограничения

- Персонажи взяты из примеров three.js (Mixamo). Для приватного прототипа это нормально, но перед любым публичным показом их нужно заменить на свои или лицензионные.
- Это браузерная игра. Реализм упирается в WebGL. Уровень Bodycam (Unreal Engine 5 + сканы Megascans) требует переезда на UE5 и мощной видеокарты.
