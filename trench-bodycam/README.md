# Окопная хроника — бодикам-шутер в окопах

Браузерный шутер от первого лица в стиле нагрудной камеры по мотивам вселенной Trench Crusade. Фанатский прототип только для личного использования.

## Как запустить

**Проще всего — по ссылке на артефакт** (её даёт Claude). Ничего ставить не нужно.

**Локально:** нужен Node.js или Python 3, потому что браузер не даёт загружать текстуры с `file://`.
- Windows: дважды кликнуть `play.bat`
- macOS / Linux: `./play.sh`
- или вручную: `node tools/serve.mjs` и открыть http://localhost:8080/

Нужен компьютер с мышью и клавиатурой и нормальной видеокартой. Качество графики выбирается в меню. Если кадров мало, игра сама снижает разрешение.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | осмотр / выстрел |
| ПКМ | вскинуть винтовку к плечу (прицел по мушке и целику) |
| R | перезарядка по одному патрону; выстрел прерывает её |
| V | удар штыком |
| Shift / C | бег / присесть |
| F | фонарь |
| Esc | пауза |

## Что внутри

### Графика

**Фотосканы Poly Haven (CC0):**
- поверхности: мокрая грязь, земляные стенки, выжженная ничейная земля, обшивка из досок, ржавое рифлёное железо, мешковина;
- модели: винтовка Мосина, противогаз, фонари «летучая мышь», армейские ящики, лопата, бочки, печка, мёртвые деревья, пни, корни, крысы.

**Окопы:**
- карта высот с земляными стенками, бруствером и воронками, часть воронок залита водой;
- реалистичная схема траншей: передняя линия с траверсами, линия поддержки, резервная линия, ходы сообщения зигзагом, сапы к постам подслушивания, блиндажи с крышами.

**Свет:**
- луна с тенями;
- нагрудный фонарь с рисунком отражателя и тенями;
- осветительные ракеты на парашюте, тени от них качаются;
- фонари и печки в окопе;
- вспышки выстрелов и далёкой артиллерии;
- ночной HDRI для отражений.

**Конвейер нагрудной камеры:**
- SSAO;
- объёмный туман: в нём видны луч фонаря с тенями и ореолы ламп;
- экранные отражения в лужах;
- bloom;
- автоэкспозиция с «дыханием», как у настоящей камеры;
- фишай, хроматическая аберрация, смаз при повороте, rolling shutter;
- шум сенсора (сильнее в темноте), перешарп, макроблоки компрессии, капли дождя на объективе.

**Дождь:** считается на GPU и виден в луче фонаря, по лужам расходятся круги.

### Враги

- **Стрелки** (легионеры у верных, солдаты Антиоха у еретиков):
  - скелетная модель с mocap-анимацией;
  - броня перекрашена по фракциям;
  - фотоскан-противогаз, каска;
  - винтовка в руках, руки держат её через IK.
- **Рукопашники:** гули с рогами и светящимися глазами или кающиеся в железных масках с цепами.
- **ИИ:** ищут путь по окопам, стрелки держат дистанцию и стреляют с разбросом.
- **Хитбоксы** по костям, попадание в голову наносит ×2.6 урона; при смерти тело падает и складывается.

### Звук

Весь синтезирован в WebAudio и пропущен через «микрофон камеры»: компрессия и перегруз. Есть эхо узкой траншеи, щелчки пролетающих пуль, свои звуки попаданий в землю, доски и железо, дождь, ветер.

## Файлы

- `index.html` — страница, меню, интерфейс камеры
- `src/` — исходники (ES-модули):
  - `main.js` — игрок и волны
  - `trenchmap.js` — схема окопов и рельеф
  - `terrain.js` — шейдер грязи
  - `dressing.js` — оснащение окопа
  - `post.js` — конвейер камеры
  - `enemies.js` — враги
  - `weapon.js` — оружие
  - `fx.js` — частицы и дождь
  - `audio.js` — звук
  - `lights.js` — свет
  - `sky.js` — небо
- `dist/game.js` — собранная игра (`npm run build`)
- `assets/` — текстуры, модели, HDRI (около 35 МБ), список источников в `assets/CREDITS.txt`
- `tools/fetch-assets.mjs` — заново скачать и обработать ассеты с Poly Haven (`npm run assets`)
- `legacy/game-v1.js` — первая версия на примитивах

Для разработки: `npm install`, затем `npm run dev` (пересборка на лету) и `npm run serve`.

## Ограничения

- Персонажи взяты из примеров three.js (Mixamo). Для приватного прототипа это нормально, но перед любым публичным показом их нужно заменить на свои или лицензионные.
- Это браузерная игра. Реализм упирается в WebGL. Уровень Bodycam (Unreal Engine 5 + сканы Megascans) требует переезда на UE5 и мощной видеокарты.
