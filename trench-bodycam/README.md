# Окопная хроника — прототип бодикам-шутера

Браузерный прототип шутера от первого лица в стиле нагрудной камеры по мотивам вселенной Trench Crusade. Фанатский проект только для личного использования.

## Как запустить

Откройте `index.html` двойным кликом в Chrome, Edge или Firefox. Сервер не нужен: three.js лежит в `vendor/`.
Нужен компьютер с мышью и клавиатурой, телефоны не поддерживаются.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | осмотр / выстрел |
| ПКМ | вскинуть винтовку (точнее, но медленнее) |
| R | перезарядка по одному патрону; выстрел прерывает её |
| V | удар штыком |
| Shift / C | бег / присесть |
| F | фонарь |
| Esc | пауза |

## Что есть

- **Две стороны.** Верные (Новый Антиох) воюют против демонов-гулей и легионеров-еретиков. Еретики воюют против кающихся и стрелков Антиоха.
- **Эффект бодикама.** Фишай-дисторсия, хроматическая аберрация, зерно, виньетка, смаз при резком повороте. Камера закреплена на теле и догоняет прицел с задержкой, качается при ходьбе. На экране отметки REC и время.
- **Окопы.** Процедурная сеть траншей (каждый запуск новая) с досками, мешками, колючкой, лужами, фонарями и блиндажами.
- **Атмосфера.** Ночь, туман, дождь, осветительные ракеты, вспышки далёкой артиллерии.
- **Винтовка.** Затворная, 5 патронов в магазине. Попадание в голову наносит ×2.6 урона.
- **Враги.** Рукопашники и стрелки с ИИ: ищут путь по окопам, держат дистанцию, стреляют с разбросом.
- **Волны и ресурсы.** Волны врагов растут. Патроны падают с убитых и лежат в ящиках в блиндажах. Здоровье восстанавливается вне боя.
- **Звук.** Весь синтезирован в коде через WebAudio: выстрелы с эхом, затвор, шаги по грязи, рык, ветер, шипение микрофона.

## Файлы

- `index.html` — разметка, меню, интерфейс камеры
- `game.js` — вся игра (рендер, уровень, ИИ, оружие, звук)
- `vendor/three.min.js` — three.js r160 (MIT)
- `build-artifact.js` — собирает однофайловую версию `dist/artifact.html` для публикации
